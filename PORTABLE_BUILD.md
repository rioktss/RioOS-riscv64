# MyKernel RISC-V64 Build Guide

This archive targets RV64 only. The supported shell build path is intended for
Termux/Android (cross-compilation), Linux, macOS, WSL, and other environments
with a compatible Bash shell and Clang/LLD.

## Required tools

```text
clang
clang++
ld.lld
python3
readelf
nm
```

The compiler must support `--target=riscv64-unknown-elf`. For runtime tests,
install a compatible `qemu-system-riscv64` build with OpenSBI; for graphical
runs, QEMU must additionally include GTK or SDL and the required VirtIO/ramfb
devices.

## Build

```sh
chmod +x build.sh run.sh run-ui.sh
./build.sh
```

Options:

```sh
./build.sh --clean       # remove generated build output before compiling
./build.sh --verbose     # print each compile operation
./build.sh --run         # build then start the serial QEMU runner
```

Outputs are under `build/riscv64/`, and `storage/disk.img` is generated by the
filesystem image builder. Both are ignored from the source-only ZIP. Host tests
and the release verifier run as part of every successful build.

## Run

```sh
./run.sh       # serial shell, QEMU virt + OpenSBI
./run-ui.sh    # graphical framebuffer UI
```

Set `QEMU`, `RIOOS_MEM`, `RIOOS_SMP`, `RIOOS_BIOS`, and (for the UI runner)
`RIOOS_DISPLAY` to override the defaults. Runtime support for framebuffer and
VirtIO input depends on the devices included by the host's QEMU build.
